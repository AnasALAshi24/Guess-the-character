# Neural Character Oracle

Neural Character Oracle is a Streamlit guessing game that identifies a character from **One Piece** or **Haikyuu!!** through an adaptive sequence of factual yes/no questions.

## Project documentation

- [Complete product and technical overview](docs/guess_the_character_overview.md)
- [Application source on the development branch](https://github.com/AnasALAshi24/Guess-the-character/tree/dev)

## Dataset snapshot

- 300 playable characters
- 150 characters from each series
- 2,195 character-trait records
- 763 unique traits

The guessing engine is deterministic and runs from the curated local dataset. It does not require an external AI model or API key.

This is an independent fan-made portfolio project and is not affiliated with or endorsed by the owners of One Piece or Haikyuu!!.
